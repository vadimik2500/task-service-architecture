\# Архитектура сервиса задач (Task Service)



\## Описание

Сервис задач (Task Service) — это веб-приложение для управления задачами пользователей.



\*\*Пользовательский сценарий:\*\* Пользователь открывает главную страницу для просмотра списка задач. Система сначала обращается к Redis cache для получения кэшированных данных. Если данных в кэше нет, API Service запрашивает их из PostgreSQL и сохраняет обратно в Redis для ускорения будущих запросов.



\## Дополнительный компонент

В качестве дополнительного компонента используется \*\*Redis cache\*\*. Он позволяет снизить нагрузку на базу данных PostgreSQL за счет кэширования часто запрашиваемых данных.
